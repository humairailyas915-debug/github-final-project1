Guidance for Team Members

All team members should follow these guidelines when working on the project:

  • Communicate clearly with other team members.
  • Keep the project files organized.
  • Test your work before making changes to the main branch.
  • Use meaningful commit messages.
  • Review your work and fix errors before submitting it.
  • Respect and support other team members.

Team Instructions

  1. Pull the latest project changes before starting work.
  2. Create a separate branch for new work.
  3. Test all changes carefully.
  4. Create a pull request when your work is ready.
  5. Merge changes only after they have been reviewed.
